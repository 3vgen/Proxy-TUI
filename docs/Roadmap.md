# Roadmap / следующие шаги

Идеи для продолжения, по приоритету. Отмечай сделанное с датой, как в [[Changelog]].

## Высокий приоритет
- [x] **Авто-ротация/здоровье по крону**: сделано 2026-09-07 — `vpn autocheck` + `vpn cron install` (ежечасно). См. [[CLI-Usage]].
- [x] **Разобраться с «мёртвыми» узлами**: диагностировано 2026-09-07 — причины разные (x509/SNI-мисматч у `ozone.ru`, reality verification failed по pbk/sid, `connection refused`). Клиентски не чинится (ключи провайдера). Итог в [[Changelog]] и [[Subscription-Nodes]].
- [ ] **Хранить sub_url как секрет** и не светить ключи (`cache/*`, конфиги) в бэкапы наружу (см. [[Security]]).

## Средний приоритет
- [ ] **IPv6 в TUN**: сейчас tun только IPv4 (`172.19.0.1/30`); у хоста IPv6 отсутствует (только link-local). Если появится IPv6-интернет — добавить address/route в tun и DNS AAAA-стратегию.
- [x] **График/статистика**: частично сделано 2026-09-07 — история тестов в `cache/history.jsonl` + команда `vpn history`. Ротации/графика пока нет (файл растёт).
- [ ] **Раздать VPN в LAN/контейнеры осознанно**: сейчас глобально на хосте; docker-контейнеры выходят через хост. При желании — per-container proxy или отдельный outbound.
- [ ] **Алиас для пользователя**: добавить в `~/.zshrc` сервера `alias vpn='~/vpn-tool/vpn'` и, возможно, удобные `vpn status`.

## Низкий приоритет / эксперименты
- [ ] Починить RU-узлы как «резерв для РФ-контента» (rutube/ozon), сохранив основной не-RU egress через правила по geo (нужны rule-sets/geoip — в 1.14 формат изменился).
- [ ] Переезд конфигов в управляемый вид: шаблон конфига в `configs/` (сейчас база = live-файл `/etc/sing-box/config.json`).
- [ ] Отдельный профиль «выключено» (direct без TUN) для сравнения/тестов без stop.
- [ ] Разобрать открытый вопрос про странные DNS-ответы DoH (см. [[Networking-Troubleshooting]] п.7).

## Как вливать изменения
1. Правь CLI/скрипты в `~/vpn-tool` (основной CLI — файл `vpn`).
2. Прогони `vpn status`, мини-тест узла, `use auto` и `vpn-off.sh`/`vpn-on.sh` (проверка отката).
3. Обнови [[Home]], [[Changelog]], [[CLI-Usage]] и эту заметку — база должна оставаться актуальной для следующего агента.
